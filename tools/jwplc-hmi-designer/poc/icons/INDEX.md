# Índice de Iconos Web y PWA: `poc/icons/`

Este directorio almacena los renders en formato PNG del isotipo del **JWPLC HMI Designer** en diferentes resoluciones para el manifiesto web (`manifest.webmanifest`), favicons y la barra de tareas.

---

## 1. Contenido

| Archivo | Dimensiones | Uso Principal |
| :--- | :---: | :--- |
| `icon-16.png` | 16 × 16 px | Favicon clásico de navegador en pestañas. |
| `icon-20.png` | 20 × 20 px | Indicador en barras de herramientas compactas. |
| `icon-24.png` | 24 × 24 px | Icono de bandeja de sistema o botones medianos. |
| `icon-32.png` | 32 × 32 px | Favicon estándar retina y vistas de lista. |
| `icon-40.png` | 40 × 40 px | Icono de aplicaciones en pantallas HiDPI. |
| `icon-48.png` | 48 × 48 px | Icono estándar de escritorio y PWA. |
| `icon-64.png` | 64 × 64 px | Manifiesto PWA de alta densidad y splash screen. |
