## Incidentes durante P3

1. `precompiled=full` hizo que Arduino dejara de descubrir indirectamente `JWPLC_GlobalPeripherals`; se corrigio con un header Auto liviano.
2. Marcadores experimentales de librerias bundled provocaron una seleccion incorrecta del backend Ethernet de Espressif; se retiraron.
3. El archive Display inicialmente no era extraido porque el core dispone de callbacks weak; se agrego un `ldflags` de anclaje.
4. El validador raw de payload fue demasiado estricto; se sustituyo por equivalencia estructural.

## Basic Core

P3 todavia no se declara final para Basic Core. El formato estandar `src/esp32/libJWPLC_Display.a` selecciona por arquitectura y no por `build.board`.

Antes de publicar el archive se debe comparar el objeto Display generado para Basic Core. Si difiere por macros de perfil, se requiere un mecanismo por perfil o separar el codigo dependiente.

## Decision

- P3 es tecnicamente viable y aporta una reduccion medible del cold build.
- Mantener fuentes como fallback.
- No publicar aun el `.a` como comun Basic/Core.
- La validacion fisica de hardware sigue pendiente antes del cierre de Alpha4.
