# Alpha14.3 — TFT 200 ms: viable pero con variación

Fecha: 2026-09-13

## Objetivo

Evaluar el full runtime realista con:

- Modbus TCP FC03 / 125 registros a 1000 req/s.
- Display dinámico activo a 200 ms (5 Hz).
- microSD inicializada y disponible, pero con append/verify fuera del scheduler.
- FRAM, RTC, TCA/I/O, botonera, SPI probe, Ethernet y Modbus TCP activos.

## Resultado físico

## Clasificación

`A14_3_TFT_200MS=TFT_200MS_VIABLE_VARIABLE`

Clasificación general del gate: **PASS_DIAGNOSTIC**.

200 ms supera holgadamente el criterio mínimo de 95 % en ambas corridas y no presenta fallos funcionales, pero el spread de 2.136 pp queda ligeramente por encima del umbral de 2.0 pp fijado para considerarlo estable en esta fase.

## Conclusión

200 ms / 5 Hz es claramente viable como política de refresco desde el punto de vista de rendimiento, pero todavía no se adopta como valor final.

Antes de afinar a 175 ms se debe repetir el mismo firmware 200 ms sin recompilar ni modificar el dispositivo, para distinguir variación natural de una frontera real de rendimiento.
