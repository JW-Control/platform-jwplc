# Alpha14 — RTU-H2C — Long-run 500 kbaud + 100 us + TCP500

Fecha: 2026-09-26

## Objetivo

Confirmar durante 600 s el candidato de producto seleccionado despues de H2B:

```txt
BAUD=500000
CONFIG=8N1
FRAME_GAP=100 us
MOTOR=ASYNC
TX=QUEUED
TCP_TARGET=500 req/s
TCP_FC03_QUANTITY=125
FULL_RUNTIME=ACTIVE
RS485=A/B/GND
W5500=26 MHz
DURATION=600 s
```

No se compila ni sube firmware. Se reutiliza el firmware H2 actualmente
cargado, que ya contiene los comandos de 500 kbaud y 100 us.

## Medicion TCP

Se mantiene una unica conexion TCP durante los 600 s.

Se generan buckets nominales de 60 s para medir:

- req/s por minuto;
- AVG/P95/P99 por minuto;
- minimo/maximo de throughput;
- promedio primera mitad;
- promedio segunda mitad;
- deriva porcentual entre mitades.

Tambien se calcula la latencia global AVG/P95/P99/MAX.

## Medicion RTU

RTU trabaja unpaced durante toda la misma ventana de 600 s.

Al final se exige:

- started = completed = success;
- rejected = 0;
- failed = 0;
- verify fails = 0;
- timeout = 0;
- CRC Master = 0;
- CRC Slave = 0;
- frames RX/TX/OK del Slave coherentes con Master.

## Runtime industrial

Se exige:

- TCP >= 99 % del target global;
- cada bucket TCP >= 99 % del target;
- cero timeout/transporte/protocolo TCP;
- cero frame timeout/bus lock timeout/protocol error del servidor;
- SD failed commits = 0;
- peripheral failure count = 0;
- baud solicitado y efectivo = 500000;
- gap efectivo = 100 us;
- motor ASYNC;
- TX queued.

## Criterio de estabilidad temporal

La deriva entre el promedio de los primeros cinco buckets y los ultimos cinco
se reporta como telemetria. Una deriva grande no se oculta aunque no haya
errores.

El gate reportara:

```txt
RTUH2C_TCP_BUCKET_MIN_REQ_S
RTUH2C_TCP_BUCKET_MAX_REQ_S
RTUH2C_TCP_FIRST_HALF_AVG_REQ_S
RTUH2C_TCP_SECOND_HALF_AVG_REQ_S
RTUH2C_TCP_HALF_DRIFT_PCT
RTUH2C_RTU_HZ
A14_RTU_H2C
```

## Decision posterior

Si H2C queda limpio, 500000 + 100 us pasa de candidato corto a candidato
qualificationado para la matriz JWPLC_FAST/AUTO.

Despues se retoma la investigacion documental del comportamiento anomalo a
230400 baud antes de cerrar la politica final de baudrates.
