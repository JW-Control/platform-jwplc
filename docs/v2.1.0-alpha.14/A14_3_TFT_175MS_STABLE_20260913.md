# Alpha14.3 — TFT 175 ms estable

Fecha: 2026-09-13

## Objetivo

Refinar la política de refresco dinámico de la TFT dentro de `FULL_RUNTIME_REALISTIC`, manteniendo:

- Display inicializado y autoload normal.
- Refresco dinámico USER activo.
- microSD inicializada, pero con workload periódico append/verify desactivado para este aislamiento.
- FRAM, RTC, TCA/I/O, botonera, SPI probe, Ethernet y Modbus TCP activos.
- FC03 / 125 registros a 1000 req/s.
- Dos corridas físicas de 60 s.

El punto de prueba fue `DISPLAY_PERIOD_MS=175`, equivalente a ~5.71 Hz.

## Conclusión

175 ms es un punto físicamente estable bajo este perfil de aislamiento:

- ambas corridas superaron ampliamente 95 %;
- el promedio fue 99.023 %;
- el spread fue sólo 0.458 pp;
- la cadencia real fue coherente con el objetivo, con 340-341 frames por minuto y gap máximo de 181 ms;
- no hubo errores TCP ni fallos de periféricos.

Comparado con el punto de 200 ms confirmado previamente, 175 ms pierde sólo 0.132 pp de promedio, por lo que mantiene prácticamente el mismo rendimiento con mayor fluidez visual.

No se adopta todavía como política final. El siguiente paso es probar 160 ms para seguir acotando el mínimo periodo estable entre el punto estable de 175 ms y el punto de 150 ms que ya mostró comportamiento de frontera.
