# Alpha14 — A14.3 PERF-S1 Server smoke físico

Fecha: `2026-09-12`

## Objetivo

Validar el harness físico inicial de rendimiento para el escenario `PERF-S1`:

```text
PC Master -> JWPLC Modbus TCP Server
FC03
1 Holding Register
10 req/s
5 s
50 requests
conexión TCP persistente
```

Este smoke no determina todavía el límite de rendimiento. Su objetivo es comprobar que la instrumentación PC ↔ JWPLC, las estadísticas internas y la captura de latencias producen resultados coherentes antes del sweep completo.

## Harness consolidado

Commit:

```text
11f394a04163c6645bdd800f2f8a0d08beaaa2ca
test(modbus-tcp): añadir harness PERF-S1 Server
```

Archivos:

```text
tools/modbus-tcp-benchmark/firmware/a14_perf_server/a14_perf_server.ino
tools/modbus-tcp-benchmark/pc/a14_perf_master_smoke.py
```

El firmware Server expone mapas suficientes para los tamaños máximos previstos de FC01/FC03/FC15/FC16 y permite por Serial:

```text
R -> reset de estadísticas
S -> snapshot de estadísticas
```

El harness PC usa Python 3.11.5 + pyserial.

## Ajuste de sincronización Serial

La primera ejecución del smoke no llegó a iniciar las requests porque el script esperaba un banner `A14_PERF_SERVER_READY` emitido una sola vez durante el arranque.

El diagnóstico confirmó que el firmware seguía activo y listo:

```text
SERVER_READY=YES
CLIENT_CONNECTED=NO
A14_3_SERVER_RUNTIME_ALIVE=PASS
A14_3_SERIAL_COMMAND_CHANNEL=PASS
```

Causa:

```text
HARNESS_SYNC_ROOT_CAUSE=MISSED_ONE_SHOT_READY
```

Se corrigió el harness para realizar un handshake activo al abrir COM14:

1. enviar `S`;
2. recibir snapshot completo;
3. exigir `SERVER_READY=YES`;
4. usar la IP objetivo configurada;
5. enviar `R` antes de iniciar el caso.

Resultado:

```text
ACTIVE_SERIAL_HANDSHAKE=PASS
A14_3_SERIAL_SYNC_FIX=PASS
```

## Conclusión

El harness PERF-S1 queda apto para pasar al sweep automatizado de FC03.

El smoke confirma que a `10 req/s` con FC03 de 1 registro no aparecen errores, timeouts, reconexiones, resets inesperados ni timeouts del lock SPI, y que la instrumentación de ambos lados produce conteos coherentes.
