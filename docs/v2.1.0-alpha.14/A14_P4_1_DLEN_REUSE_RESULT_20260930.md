## Decisión

transacciones/periféricos. El cache de longitud existe únicamente durante una
invocación de `jwplcSpiReadBytesReuseFifoNL()`.

- 1000 req/s Modbus TCP;
- RTU 50 Hz;
- P95/P99;
- DataLog;
- Display HMI dirty/on-demand;
- periféricos y estabilidad física.
