# Alpha15 · A15-4B — Fuentes en JWPLC_TFT 0.3.0

Fecha: `2026-10-17`

```text
JWPLC_TFT=0.3.0
API=setFont(const JWPLC_TFTFont&), setTextDatum, setTextPadding, drawString, font(), textDatum(), textPadding()
FUENTES=JWPLC_FONT_GLCD + 24 FreeFonts (SANS/SERIF/MONO, normal/bold, 9/12/18/24 pt)
FONT2_FONT4=NO (agregan ~9.3 KB a todo sketch aunque no se usen)
ABI_COMPAT=PASS (0 símbolos públicos eliminados; imports de otras .a resueltos)
CLASS_LAYOUT=SIN CAMBIOS (estado de fuente en variables estáticas del .cpp)
PHYSICAL=[no verificado]
```

## Decisión de diseño

La propuesta de `bf0fba1` (André) usaba un `enum` y un `switch` con las 24 FreeFonts dentro de
`syncTextState()`. Eso hubiera enlazado todas las fuentes en cualquier sketch que imprima texto y,
además, agregaba miembros a `JWPLC_TFTClass` (ABI). La versión publicada:

- Cada fuente es un objeto constante `extern const JWPLC_TFTFont JWPLC_FONT_<ID>` con un puntero
  opaco a su `GFXfont`. `setFont()` recibe una referencia: el enlazador (`--gc-sections`) sólo
  conserva las fuentes que el sketch nombra.
- Fuente, datum y padding se guardan en estáticos del `.cpp` (`g_font`, `g_datum`, `g_padding`).
- `tft_setup.h`: `LOAD_GLCD` + `LOAD_GFXFF`. `JWPLC_TFT.cpp` falla en compilación si alguien
  habilita `LOAD_FONT2/4/6/7/8`.

## Chequeo ABI

`tools/alpha15/regenerate_libJWPLC_TFT.sh build`:

```text
PUBLIC_SYMBOLS_REMOVED=0
PUBLIC_SYMBOLS_ADDED=32   (25 JWPLC_FONT_* + 7 métodos)
IMPORTS_FROM_OTHER_LIBS_MISSING=0
ABI_COMPAT=PASS
```

Las funciones internas de TFT_eSPI dentro del `.a` cambian de tamaño al habilitar `LOAD_GFXFF`;
ninguna otra librería del package las importa (sólo `libJWPLC_Display.a` importa
`JWPLC_TFTClass::*`, todos presentes).

## Designer

- `designer-fonts.js`: `isSupported()` / `effectiveId()`; GLCD y FreeFonts habilitadas, Font2/Font4
  deshabilitadas ("no incluida en el firmware"). `cppSymbol(id)` → `JWPLC_FONT_<id>`.
- Codegen RAW_TEXT con FreeFont:

  ```cpp
  #if JWPLC_HMI_TFT_FONTS          // JWPLC_TFT >= 0.3.0
  tft.setFont(JWPLC_FONT_SANS_9); tft.setTextDatum(JWPLC_TFTDatum::TOP_LEFT);
  tft.drawString("...", x, y); tft.setFont(JWPLC_FONT_GLCD);
  #else                            // package publicado: GLCD
  tft.setCursor(x, y); tft.print("...");
  #endif
  ```

- Compilación ESP32 del header de prueba: 0.3.0 → 430901 B; 0.1.0 forzado → 425933 B. Ambos sin
  diagnósticos.
