# A20_1 · JWPLC_WiFi y JWPLC_Red 0.1.0 (28/11/2026)

```text
A20_1_COMPILA_ESP32=PASS
A20_1_RED_CABLE_SIM=PASS
A20_1_WIFI_PLACA=PENDING        (requiere placa y router: taller)
A20_1_AUTO_CABLE_A_WIFI=PENDING (requiere placa: desenchufar el cable con 01.Red_Cable_o_WiFi)
```

## Qué entra

- `JWPLC_WiFi` 0.1.0: `connect()` no bloqueante, tarea propia en el núcleo 0, reconexión cada 15 s (30 s tras
  clave incorrecta o red no encontrada), estado con motivo, señal en dBm y %, IP fija opcional, nombre
  `jwplc-XXXX`.
- `JWPLC_Red` 0.1.0: modos `useEthernet()` (por defecto), `useWiFi()`, `useAuto()` (cable primero) y
  `JWPLC_RedClient`, un `Client` de Arduino que elige la red en cada `connect()`. La parte WiFi se engancha
  por símbolos débiles definidos en `JWPLC_WiFi.cpp`.
- Ejemplos: `JWPLC_WiFi/01.WiFi_Conectar`, `JWPLC_Red/01.Red_Cable_o_WiFi`, `JWPLC_Red/02.Red_Solo_Cable`.
