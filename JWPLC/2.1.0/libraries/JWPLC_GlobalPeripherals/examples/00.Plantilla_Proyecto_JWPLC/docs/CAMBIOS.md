# Bitácora de cambios del proyecto

Una entrada por cada versión que se carga en un equipo. La más reciente arriba.
La versión es la de `PROYECTO_VERSION` en `A_Config.h`.

|---|---|---|---|---|
| 1.0.0 | aaaa-mm-dd | | | Versión inicial creada desde la plantilla JWPLC |
